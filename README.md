# Viết Để Hiểu - Trang giới thiệu sách

Trang web tĩnh giới thiệu sách, làm bằng Bootstrap 5 (CDN), responsive theo mọi kích thước màn hình.

Gồm các phần: Header và Book Overview, Author, Features, Prices, Download, Reader's Say, Footer.

## Chạy thử
Mở `index.html` bằng trình duyệt (cần internet để tải Bootstrap từ CDN).
